# 脑电波形显示滤波记录

- 日期：2026 年 11 月 3 日
- 涉及文件：`lsl_EEG/web/frontend.html`
- 测试文件：`lsl_EEG/tests/display-filter-test.cjs`
- 状态：浏览器模拟测试通过，实际设备采集效果待确认

## 问题与目标

实时波形原先没有高通、低通和陷波选项，受到慢漂移、高频成分和工频干扰时不易观察。希望在波形上方分别选择是否启用这三种显示滤波，并自行设置频率。

## 实现方法

1. 在波形上方增加高通、低通、陷波三个按钮和对应的频率输入框，默认全部关闭。点击按钮切换启用状态，紫色表示开启。
2. 参考图中的数值作为可修改的初始值：高通 0.3 Hz、低通 60 Hz、陷波 50 Hz。它们不是适合所有采样率或研究方案的固定配置。
3. 采用实时二阶 IIR 滤波：高通和低通为 Butterworth 型（Q = 1/√2），陷波 Q = 30；各通道分别维护滤波状态，连续数据包之间保持状态。切换开关或频率后，用当前窗口内的数据重新生成显示结果；由此窗口起点附近可能出现短暂的边界过渡。
4. 频率必须大于 0 且小于当前采样率的一半；同时启用高通和低通时，高通频率必须小于低通频率。设置不合法时提示并保留已生效设置；采样率变化使已启用的滤波频率无效时，自动关闭对应滤波并提示。
5. 滤波只作用于前端显示缓冲，波形旁的 RMS 和超量程比例也基于显示波形计算；不修改后端接收、原始采集数据或疲劳检测算法。关闭全部滤波时仍保留页面原有的显示用去直流和增益处理。

## 验证结果

- 用 250 Hz 采样率下的 10 Hz 与 50 Hz 混合模拟信号，验证高通、低通和 50 Hz 陷波对相应频率的衰减，以及关闭滤波后显示恢复。
- 验证连续分包处理、无效频率和高低通顺序的提示、采样率变化时的自动关闭。
- 重新运行波形绘制节流和通道高度调整的浏览器测试。实际 BLOOM 数据效果仍需连接设备验证。
